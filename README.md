# Vehicle Mobility and Autonomous Ground-Vehicle Behaviour Under Changing Terrain Conditions

## Overview

This project investigates how changing road and terrain conditions influence tire forces, vehicle stability, traction, and ground-vehicle mobility.

The project combines:

- Tire-road interaction
- Vehicle dynamics
- Road-condition modelling
- Terramechanics
- Terrain-dependent traction
- Autonomous ground-vehicle simulation

## Research Direction

The initial study focuses on tire grip under dry, wet, and snow-covered road conditions using MATLAB.

The project is subsequently extended toward tire-terrain interaction and autonomous ground-vehicle mobility under changing terrain conditions.
